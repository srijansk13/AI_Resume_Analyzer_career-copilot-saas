# 🚀 Local Setup

## Clone Repository

```bash
git clone YOUR_REPO_LINK
cd AI_Resume_Analyzer
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create:

```bash
.env.local
```

Add:

```env
MONGODB_URI=
JWT_SECRET=
EMAIL_USER=
EMAIL_PASS=
GEMINI_API_KEYS=
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

---

## Run Development Server

```bash
npm run dev
```

---

## Production Build

```bash
npm run build
```
